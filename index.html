Recuperación de una clave al menor costo

Una estación cifra cada mensaje m con una clave secreta fija k mediante c = (m · k) mod n. Se conoce n y un catálogo de mensajes, cada uno con un costo positivo. Antes de ver cualquier respuesta hay que elegir el conjunto de consultas de menor costo que permita identificar cualquier clave entre 0 y n − 1. Criterio: un conjunto distingue todas las claves si y sólo si gcd(n, m₁, …, mₜ) = 1; si no, las claves 0 y n/g dan las mismas respuestas.
